Product

Easy PDF Free

Ad-free PDF reader with no accounts, made to open a file with one tap from WhatsApp. Works as a web app (PDF.js) and as an Android app with Capacitor.

Live demo ↗ Code ↗

Highlights

What it includes

  • Opens PDFs from the file picker, by dragging, or from other apps: tapping a PDF in WhatsApp opens it directly.
  • Large, minimal controls: zoom with + and −, text search, night mode, share and save to Downloads.
  • Asks for the password if the PDF is protected.
  • No ads, no accounts and no servers: the PDF never leaves the phone.
  • Web app with PDF.js bundled locally (no CDN) and an Android app with Capacitor, tested on a Samsung S25.

Tech stack

Built with

  • PDF.js
  • Capacitor
  • Android
  • PWA
